# Klangaufnahmen

Alle Aufnahmen in diesem Ordner stammen von **Kenney** (www.kenney.nl) und stehen unter
**CC0 1.0** (gemeinfrei, keine Namensnennung nötig – wir nennen Kenney trotzdem gern).

| Datei | Herkunft |
|---|---|
| kenney-blaster.wav | Kenney Starter Kit FPS – sounds/blaster.ogg |
| kenney-blaster-repeater.wav | Kenney Starter Kit FPS – sounds/blaster_repeater.ogg |
| kenney-enemy-attack.wav | Kenney Starter Kit FPS – sounds/enemy_attack.ogg |
| kenney-enemy-destroy.wav | Kenney Starter Kit FPS – sounds/enemy_destroy.ogg |
| kenney-enemy-hurt.wav | Kenney Starter Kit FPS – sounds/enemy_hurt.ogg |
| kenney-impact.wav | Kenney Starter Kit Racing – audio/impact.ogg |
| kenney-break.wav | Kenney Starter Kit 3D Platformer – sounds/break.ogg |

Übernommen mit `node scripts/import-sound.mjs <datei> <name>`: verlustfrei als WAV (16 Bit, 44,1 kHz),
Spitze auf −1 dBFS normalisiert, Stille am Ende entfernt. Im Spiel werden sie je Waffe in Tonhöhe und Klangfarbe
verändert und mit synthetischen Anteilen (Knall, Bassschlag, Hall) gemischt.

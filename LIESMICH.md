# X4 Sektorbau – Einzeldatei zum Herunterladen

Stand: Version 195 (Code-Stand 83455b6 auf dem Arbeitszweig) – mit Kha'ak-Invasion und lückenlosen Dreiecks-Clustern.

1. `x4-sektorbau.zip` herunterladen (auf die Datei klicken, dann rechts oben „Download“ / „View raw“).
2. Entpacken – darin liegt eine einzige `index.html` (≈ 102 MB, alle Bilder und Lieder in voller Qualität).
3. `index.html` im Browser öffnen. Läuft offline, ohne Server; das Laden dauert wegen der Größe ein paar Sekunden.

Die Einzeldatei speichert ihren Spielstand getrennt von der Online-Version.
Neue Versionen ersetzen hier jeweils die alte (dieser Zweig enthält nur die Download-Datei, keinen Quellcode).
